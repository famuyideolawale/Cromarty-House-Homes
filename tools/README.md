# Model tools

Python scripts that trace `model.js` from the architect's PDFs (PyMuPDF, NumPy, SciPy, scikit-image).
They expect `warrant.pdf` (first-floor warrant plan), `plan1.pdf` and `plan2.pdf` (planning drawings) in the working folder.
The drawings themselves are not stored in this repository.

Order: extract.py → ex2.py → gf.py → build2.py → build3.py → build4.py → build5.py → build6.py → build7.py → assemble.py → final.py
